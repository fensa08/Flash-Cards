Positional encoding

Attention is permutation-invariant: shuffle the tokens and the maths gives you the same answer. Position has to be injected into the embeddings rather than inferred from the operation itself.

Why it matters
Sinusoidal encodings let a model extrapolate to sequence lengths it never saw in training — learned embeddings usually cannot.

The sinusoidal formulation

PE(pos, 2i)  = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

Each dimension traces a sinusoid of a different wavelength, so relative offsets become linear functions of the encoding — the property that makes attention able to reason about "three tokens back".

Q7 / 20
Why do sinusoidal positional encodings generalise to longer sequences than learned ones?
Relative offsets are a linear function of sinusoidal encodings, so the pattern continues past training lengths. Learned tables simply have no row for position 5,000.
